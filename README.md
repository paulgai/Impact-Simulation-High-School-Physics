# Προσομοίωση Κρούσεων

Διαδραστική εκπαιδευτική εφαρμογή για τη μελέτη των κρούσεων στη Φυσική. Ο μαθητής μπορεί να μεταβάλλει τις αρχικές συνθήκες, να παρακολουθεί την κίνηση πριν και μετά την κρούση και να συγκρίνει τα αποτελέσματα της προσομοίωσης με τους θεωρητικούς υπολογισμούς.

**[Άνοιγμα της προσομοίωσης](https://paulgai.github.io/Impact-Simulation-High-School-Physics/)**

## Δυνατότητες

- Επιλογή γεωμετρίας και είδους κρούσης.
- Ρύθμιση αρχικών θέσεων, μαζών, ακτίνων και αρχικών ταχυτήτων.
- Ρύθμιση γωνίας πρόσκρουσης στις πλάγιες κρούσεις και στις κρούσεις με ακίνητο σώμα μεγάλης μάζας.
- Επιλογή ποσοστού απώλειας κινητικής ενέργειας στις ανελαστικές κρούσεις, μέχρι τη μέγιστη φυσικά επιτρεπτή τιμή.
- Αναπαραγωγή, παύση, επανεκκίνηση και κίνηση ανά καρέ.
- Άμεση μετάβαση στις καταστάσεις «Ακριβώς πριν από την κρούση» και «Ακριβώς μετά από την κρούση».
- Απεικόνιση διανυσμάτων ταχύτητας και, όπου χρειάζεται, γεωμετρικών χαρακτηριστικών.
- Πάνελ αποτελεσμάτων με θέσεις, σημείο κρούσης, ταχύτητες, γωνίες, κινητικές ενέργειες και απώλεια κινητικής ενέργειας. Ο χρόνος κρούσης δεν εμφανίζεται στο πάνελ.
- Μεγέθυνση, σμίκρυνση, μετακίνηση της προβολής, πλήρης οθόνη και φωτεινό ή σκοτεινό θέμα.
- Ηχητικό εφέ κατά τη στιγμή της κρούσης.

## Διαθέσιμες κρούσεις

| Γεωμετρία | Ελαστική | Πλαστική | Ανελαστική χωρίς συσσωμάτωμα |
|---|:---:|:---:|:---:|
| Κεντρική (μετωπική) | ✓ | ✓ | ✓ |
| Έκκεντρη | ✓ | ✓ | — |
| Πλάγια με σημειακές μάζες | ✓ | ✓ | — |
| Με ακίνητο σώμα μεγάλης μάζας | ✓ | — | ✓ |

## Γρήγορη χρήση

1. Επίλεξε τη γεωμετρία και το είδος της κρούσης από το αριστερό πάνελ.
2. Όρισε τις αρχικές συνθήκες με τους ολισθητές ή πληκτρολογώντας τις επιθυμητές τιμές.
3. Πάτησε **Επανεκκίνηση** για να εφαρμοστούν οι ρυθμίσεις από την αρχή.
4. Πάτησε **Έναρξη** για να παρακολουθήσεις την κίνηση.
5. Χρησιμοποίησε τα κουμπιά **Ακριβώς πριν από την κρούση** και **Ακριβώς μετά από την κρούση** για ακριβή σύγκριση των μεγεθών.
6. Διάβασε τις αριθμητικές τιμές από το δεξί πάνελ αποτελεσμάτων.

Αν οι επιλεγμένες αρχικές συνθήκες δεν οδηγούν σε σύγκρουση, η εφαρμογή εμφανίζει σχετικό μήνυμα.

## Φυσικό μοντέλο

Η προσομοίωση χρησιμοποιεί αλγεβρικές ταχύτητες: το πρόσημο δηλώνει τη φορά κίνησης ως προς τον επιλεγμένο άξονα.

Στις κεντρικές κρούσεις εφαρμόζεται η διατήρηση της ορμής:

```text
m₁u₁ + m₂u₂ = m₁u₁′ + m₂u₂′
```

- **Ελαστική κρούση:** διατηρούνται η ορμή και η συνολική κινητική ενέργεια.
- **Πλαστική κρούση:** τα σώματα σχηματίζουν συσσωμάτωμα και κινούνται με κοινή ταχύτητα

  ```text
  v′ = (m₁u₁ + m₂u₂) / (m₁ + m₂)
  ```

- **Ανελαστική κρούση χωρίς συσσωμάτωμα:** η ορμή διατηρείται, ενώ η κινητική ενέργεια μειώνεται κατά το επιλεγμένο ποσοστό. Η εφαρμογή περιορίζει αυτόματα το ποσοστό στη μέγιστη τιμή που επιτρέπουν οι αρχικές συνθήκες.

Στην κεντρική κρούση, η επιλογή `R₁ = R₂ = 0` αντιστοιχεί σε σημειακά σώματα. Για μη μηδενικές ακτίνες, η κρούση αρχίζει όταν οι επιφάνειες των σωμάτων έρθουν σε επαφή. Στην πλαστική έκκεντρη κρούση λαμβάνονται υπόψη τόσο η μεταφορική όσο και η περιστροφική κίνηση του συσσωματώματος.

Το μοντέλο είναι ιδανικό: τα σώματα κινούνται χωρίς εξωτερικές δυνάμεις και η διάρκεια της κρούσης θεωρείται αμελητέα.

## Τοπική εκτέλεση

Δεν απαιτείται εγκατάσταση πακέτων ή διαδικασία μεταγλώττισης. Από τον βασικό φάκελο του έργου μπορεί να ξεκινήσει ένας απλός τοπικός διακομιστής:

```bash
python -m http.server 8000
```

Στη συνέχεια άνοιξε στον φυλλομετρητή:

```text
http://localhost:8000
```

Για τη φόρτωση των Bootstrap, Bootstrap Icons και KaTeX απαιτείται σύνδεση στο διαδίκτυο, επειδή οι βιβλιοθήκες παρέχονται μέσω CDN.

## Δομή του έργου

```text
├── index.html       # Διεπαφή και στοιχεία ελέγχου
├── styles.css       # Εμφάνιση και προσαρμοστική διάταξη
├── script.js        # Φυσικό μοντέλο, κίνηση και αποτελέσματα
├── assets/          # Αρχεία ήχου και λοιπά στοιχεία
```

Τα φύλλα εργασίας περιλαμβάνουν αρχεία LaTeX και έτοιμα PDF για χρήση στην τάξη.
